# ちゃっとスタンプメーカー 1.0.6

写真やイラストから、好きな言葉で動くスタンプを作り、Delta Chatの仲間と共有できるwebxdcアプリです。

## 最初の使い方

1. Delta Chatで、アプリを使う相手がいるチャットを開きます。
2. `chat-stamp-maker-1.0.6.xdc` をファイルとして添付して送ります。
3. 添付アプリの開始ボタンを押します。相手にも同じ添付アプリを開いてもらいます。
4. 「画像を選ぶ」で写真やイラストを選びます。見本キャラのままでも試せます。
5. 言葉のカテゴリを選び、使いたいスタンプを押します。
6. 「○個を共有する」で、アプリ内の共有一覧へ登録します。
7. 「みんなのスタンプ」で使いたいスタンプを押し、「チャットに送る」または「保存する」を選びます。

「チャットに送る」は、画像をDelta Chatへ渡す操作です。送信先と添付内容を確認し、Delta Chat側で送信を完了してください。

## 主な機能

- ヘッダーの「日本語」「English」でUIを切り替える。
- 日本語の「丁寧・あいさつ」21種類、「カジュアル」14種類、「業務用」26種類を使う。
- 独立した「English Greetings」の英語10種類を使う。
- 「じぶん」で14文字以内の自由文、絵文字、ポーズ、文字色を組み合わせる。
- タッチ・かたち・うごき・背景・枠、元画像の位置や大きさを変える。
- 名前入りハンコ6種類を作る。ハンコ専用の大きさを25〜100%で調整する。
- 全種類のスタンプについて、送信・保存時の全体の大きさ、画像枠の形、画像の長辺を変える。
- 自分の通常スタンプを共有後に訂正する。共有一覧から削除する。
- 画像・一覧・追加済み自由文・各種設定を、JSONのバックアップで新版へ引き継ぐ。

UIの言語を変えても、スタンプの文言・画像・選択中のチェックは変わりません。日本語UIで英語のスタンプを、英語UIで日本語のスタンプを選べます。

「キャラ化」は端末内でのフィルターや変形です。AIが新しい手足や表情を描き直す機能ではありません。「背景 とうめい」は元写真の背景を自動で切り抜く機能ではありません。

## 三つの大きさ設定

| 設定 | 使う場面 |
|---|---|
| 元画像の大きさ | 写真やイラストの切り抜き調整。ハンコには反映しない |
| ハンコの大きさ | ハンコ作成時の印影を25〜100%で調整。初期値45% |
| スタンプ全体の大きさ | 共有一覧から送信・保存するとき、文字も含む全体を25〜100%で調整 |

送信・保存の画像枠は正方形・横長・縦長、長辺は96・128・192・256pxです。動き付きはGIF、動きなしは透過PNGです。

Delta Chat上の画像枠や吹き出しの実際の表示寸法を厳密に指定することはできません。画像の形・画素数・余白を調整する方式です。小さい画像を端末が拡大表示する場合もあります。

## バックアップで引き継ぐ

1. 更新前に「データの引き継ぎ バックアップと復元」を開きます。
2. 「バックアップを保存」でJSONを保存し、ファイルがあることを確認します。「バックアップをチャットへ」で保管先のチャットへ渡す方法もあります。
3. 新しい版のアプリを添付して開き、「バックアップを選ぶ」でJSONを選びます。
4. 件数と案内を確認して「内容を確認して復元する」を押します。
5. 内容を確認した後、必要なら「復元スタンプをみんなに共有」でメンバーへコピーを共有します。

復元だけでは外部へ送信しません。最初は自分の端末にコピーを作ります。同じバックアップからのスタンプ・自由文は重複を除いて追加し、画像と各種設定はバックアップの内容へ置き換えます。

1.0.4以降のバックアップ形式に対応しています。1.0.3以前には書き出し機能がなく、新版から別添付の旧版データを直接取り出せません。必要な旧版の添付アプリは残してください。

バックアップには写真や作成者名が含まれ、ファイル自体は暗号化されません。保管先・渡す相手を確認してください。上限は20MB、スタンプと自由文はそれぞれ500件です。

## 使う前に覚えておくこと

- 同じチャットの同じ添付アプリが共有場所です。別に添付したコピーに履歴は自動で移りません。
- 複数個の共有は送信間隔の制限により時間がかかります。進捗を確認してください。
- 共有すると、スタンプ画像と訂正用の加工済み元画像がメンバーに渡ります。
- ハンコや、訂正用元画像情報のないスタンプは更新できません。
- 一覧から削除しても、すでに送信・保存された画像は消えません。
- 端末内に保存される設定だけに頼らず、更新前にバックアップをファイルへ書き出してください。

## 動作確認について

実ブラウザで日英切替、文化別カテゴリ、PNG・GIFのサイズ調整、独立した保存領域間でのバックアップ復元などを確認しています。マニュアルの画面図も1.0.6のブラウザ試用画面です。Delta Chatの実機での端末間送信・受信表示は未確認です。

PDFは全ページを画像化して確認しています。HTMLはデスクトップ幅とスマートフォン幅の表示を確認しています。Word版は編集可能な文書として作成し構造を確認していますが、この作成環境にはWord文書を再描画するソフトがないため、Wordで開いたときの改ページは未確認です。固定レイアウトで読む・印刷する場合はPDF版を利用してください。
